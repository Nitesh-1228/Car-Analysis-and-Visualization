->Car Dataset Analysis and Visualization

This is a beginner-friendly Python project that analyzes and visualizes a car dataset. The program uses **Pandas**, **NumPy**, and **Matplotlib** to read data from a CSV file, clean it, calculate basic statistics, and generate various plots.
The script removes duplicate entries and filters out cars with very low sales. Missing values are filled with column-wise averages to make the dataset more usable. It then calculates useful insights like the average price of cars, the most common engine size, and total sales. Group-wise analysis is done to find average prices based on engine sizes.
For visualization, the project includes a histogram of car prices, a scatter plot between engine size and price, a pie chart of price ranges, a line graph for horsepower, and a bar chart showing average engine size by fuel efficiency. These help in understanding trends and patterns within the dataset.

->Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

->Features:
This project includes several useful features such as loading a dataset from a CSV file, cleaning the data by removing duplicates and low-sale records, and filling missing values with averages. It also performs basic statistical analysis like calculating mean, mode, and sum for selected columns. Additionally, the script groups data by engine size to analyze price trends, and creates visualizations including a histogram, scatter plot, pie chart, line graph, and bar chart to help better understand the dataset.
